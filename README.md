# 룬 진형 체스 — 서버 버전

게임 파일(`public/index.html`)과, 온라인 대전을 중계하는 Node.js 서버(`server.js`)가 들어 있습니다.

## 실행 방법

[Node.js](https://nodejs.org) 18 이상이 필요합니다.

```bash
npm install
npm start
```

브라우저에서 `http://localhost:3000` 을 열면 됩니다. 포트를 바꾸려면 `PORT=8080 npm start` 처럼 실행하세요.

## 친구와 온라인 대전하기

1. 한 사람이 로비에서 **온라인 대전 → 방 만들기**를 누르면 방 코드가 나옵니다.
2. 다른 사람이 같은 서버 주소로 접속해서 방 코드를 입력하고 **참가**를 누릅니다.
3. 각자 군단을 편성하고 **준비 완료**를 누르면 대전이 시작됩니다.

새로고침하거나 연결이 잠깐 끊겨도 같은 방 코드로 다시 들어가면 이어서 할 수 있습니다(같은 브라우저 기준).

### 집 밖의 친구와 하려면

`localhost`는 내 컴퓨터에서만 열립니다. 다른 곳의 친구와 하려면 아래 중 하나를 쓰세요.

- **클라우드에 올리기 (추천)**: Render, Railway, Fly.io 같은 Node.js 호스팅에 이 폴더를 그대로 올리고, 시작 명령을 `npm start`로 지정합니다. WebSocket을 지원하는 곳이어야 합니다. `https://` 주소로 접속하면 자동으로 `wss://`를 씁니다.
- **같은 와이파이**: 친구가 `http://내컴퓨터IP:3000` 으로 접속합니다.
- **내 컴퓨터를 외부에 열기**: 공유기 포트포워딩(3000번) 또는 ngrok, Cloudflare Tunnel 같은 터널 도구를 씁니다.

## 구성

| 파일 | 내용 |
|---|---|
| `public/index.html` | 게임 전체 (엔진, 스프라이트, 음악, UI) |
| `server.js` | 정적 파일 제공 + `/ws` WebSocket 방 중계 |
| `package.json` | 의존성 (`ws`) |

서버는 게임 규칙을 계산하지 않고 양쪽의 행동 기록만 중계합니다. 엔진이 결정론적이어서 두 브라우저가 같은 기록으로 같은 판을 재현합니다. 방 하나에서 두 명이 대전합니다(방 만든 사람 = 청람, 참가한 사람 = 홍염). `/health` 주소는 호스팅 헬스체크용입니다.
